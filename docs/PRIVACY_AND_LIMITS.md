# 隐私与结论边界

本地网关默认只接受 loopback 和固定路由。配置只接受环境变量名，不接受明文认证字段。Local token 与上游 key 从明确配置的环境变量读取，仅用于固定端点认证；不读取历史聊天、订阅 auth.json 或钥匙串。控制请求与上游请求禁用环境代理、禁用重定向。

业务实体逐块转发，除了必要的认证替换及连接/长度类传输头整理，不改 model、input、messages、tools、预算或上下文。监测只接收有界内存副本。解析、检测、磁盘和终端通知在独立队列/后台执行；队列满时丢弃观察，显示 monitoring_degraded。网关进程或操作系统故障仍会中断连接。

持久数据为 requests.jsonl、incidents.jsonl、events.jsonl、单事件 Markdown、状态、预算和通知游标。白名单包含模型声明、HTTP 状态、协议完整性、停止原因、timing、条件分档和上游自报 usage。无请求/回答/工具参数/推理正文、Authorization/Cookie。会话标识用本机随机 32 字节关联密钥做 HMAC。关联密钥用于本地摘要，不是 API Key；备份/导出需按自己的隐私需求管理。

已知配置 Key 和 URL 在外部标签里先精确替换，再截断。日志只使用固定错误类别，aiohttp HTTP 错误不打印原始异常包。Agent hook 输入可能含真实对话，通知程序完全忽略。报告内的标签永远是不可信数据，不作为命令执行。此方式不能识别未知敏感文本被服务商恶意塞进 model 标签；禁止分享真实流量报告前仍应人工检查标签元数据。

默认保留 14 天；启动与 guard cleanup 清理记录和事件报告。预算保留 UTC 滑动 hour/day 窗口，不因重启清零；保留期限清理不重置有效预算。活动基线在内存中，重启重新学习；不把旧状态快照当成新运行的已知正常。通知游标独立持久化，避免重复展示同一 incident。

服务变化是按声明条件分组的描述性比较。输入字符/实体规模分档、cache、自报 tokens 都只是代理信号；任务难度、隐藏系统提示、网络、排队与采样仍可变化。没有统计误报校准、p 值、纯度分或已验证准确率。当前阈值为 20 基线样本/20 当前样本、错误率增量≥0.25 或耗时中位数≥2倍，不能把一次失败叫换模。

后台合成探针的标准答案来自现有确定性代码与人工可检查题目，材料仍标 synthetic_unverified。参考 trusted 标记由使用者设置，不证明官方身份。条件相同与参考自身稳定只是行为比较的前提，不是权重认证。模型标签和可见行为完全相同时，结果必须是 unverified。

未验收：真实收费 API、中转兼容性、真实流量持续运行、模型身份指纹/误报漏报率、原生 WebSocket/Gemini、多模态、macOS 用户实际看到系统弹窗、MCP 服务、OS 进程监督安装器。当前两个真实客户端测试仅连接模拟中转，绝不能宣传已安装并正在保护用户的订阅连接。
