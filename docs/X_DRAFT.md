你买的是旗舰模型，收到的到底是什么？问它“你是谁”没用，返回字段里写着哪个模型，也不能直接证明。

我用 Codex 做了个开源小工具 RelayAudit，给 API 中转站跑一组能复现的测试：推理、代码追踪、JSON、工具调用、上下文检索。可以和自己信任的参考端点对照，报告答题差异、接口错误和响应时间。Key 放在自己电脑上，测试请求直接发给你配置的端点。

先把边界讲清楚：它现在是初版，能给出异常证据，不能保证认出真实模型。几道题答错不等于掉包，测试全过也不等于永远不掺水。当前完成了离线演示和本地接口测试，真实站点的误报、漏报还需要校准。

源码、测试和演示都放这里了：https://github.com/zhouey314-cloud/relay-audit。欢迎拿自己的测试额度跑一下，把参数、时间和脱敏报告一起提 Issue；比一句“感觉降智了”更容易把问题查清楚。
